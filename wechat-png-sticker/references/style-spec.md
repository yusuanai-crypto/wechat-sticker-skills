# 静态 PNG 风格规范

## 固定视觉语言

- 画面：正方形、Q 版半身或大头半身，人物主体清楚，在 240×240 像素下仍可辨认。
- 人物：保留稳定可见的脸型、发型、眼镜、服装色块和标志性配饰；减少皮肤纹理与写实细节。
- 线条：干净的深色轮廓，色块清楚，阴影简洁。
- 外沿：合成阶段给人物统一添加白色贴纸描边，生成母图时不要画第二层外沿。
- 背景：真实 alpha 透明，不要棋盘格、纯色底、场景、地面或投影。
- 文案：逐字匹配用户文本，不由图像模型绘制。默认使用粗手写漫画标题字，采用“白色主字＋黄橙关键词＋粗黑内描边＋白色外描边＋右下灰影”的贴纸层次。
- 构图安全区：人物与画布边缘留足白边空间；字幕位于顶部或底部，不压住眼睛、手势和主要表情。

## 文字风格匹配

先看已确认的 Q 版母图，再决定文字尺寸和叠放位置；默认保持以下视觉结构：

- 字形：首选粗重、紧凑、带自然手写起伏的中文漫画标题字，字面要饱满且略有斜势。避免幼圆、宋体、仿宋、细黑体、规则几何黑体和纤细书法字；不要随机逐字旋转、缩放或混搭字体。
- 主次配色：普通文字使用白色；原文中若有明确核心词，只高亮一个连续且只出现一次的精确子串，使用暖黄或黄橙色，默认 `#FFB21A`。短文案或没有明确核心词时保持全白，不为了配色改字、添字或拆词。
- 描边层次：文字先加约为字号 11% 的粗黑内描边，再加约为字号 6% 的白色外描边。黑边负责清楚有力，白边负责把整组字从人物与透明背景中托起；两层都必须连续，不能互换顺序。
- 阴影：在右下方添加约为字号 6% 偏移的短灰影，颜色接近 `#626262A0`。阴影只增加贴纸立体感，不做长投影、发光、模糊光晕或大面积底板。
- 版式：短文案优先单行、紧凑居中，整体略有手写动势。底部字幕可上提约画布宽度的 3%，轻叠人物肩部或下缘，但不得遮挡眼睛、嘴部、核心手势和关键道具；顶部字幕不强行叠人物。
- 可读性：240×240 中仍应一眼读清白字、黄橙关键词、黑内描边和白外描边；若拥挤，先缩小字号，再减少高亮，最后才换行。
- 一致性：同一套表情优先复用已确认的字体、主字色、高亮色、双层描边、阴影和相对字号，除非用户明确要求变化。

合成脚本在 Windows 上优先使用系统“华文行楷”，再回退到华文新魏、华文琥珀和通用粗体。`--highlight-text` 只接受原文中唯一出现的单行子串；需要替换字体时，使用 `--font` 指向有权使用且支持中文的粗手写 `.ttf` 或 `.ttc` 文件。默认颜色已按上述层次固定；只有用户明确要求随画面取色时，才对 `--text-fill`、`--text-stroke` 或其他颜色参数传入 `auto`。必须检查 240×240 成图。

## 多截图与同套一致性

多张截图可共同用于识别人物和选择姿态，但每枚成品只有一个静态时刻：

- 必须锁定：脸型、发型、眼镜、服装、色板、线条、人物比例、背景透明度和字幕安全区。
- 允许按表情变化：手臂和手掌位置、手势、嘴眼表情、头部朝向、身体姿态，以及杯子等道具的持握状态。
- 连续截图呈现完整动作时，选择最清晰、最有表现力且与文案最匹配的瞬间，不合成中间帧。
- 两张截图中若有两个人，必须确认用户要保留一人还是两人；若保留两人，分别提炼身份锚点，不能合并人物。
- 同一套后续表情使用已确认母图作为风格与身份参考，不把每枚表情当成互不相关的新设计。

## 姿态与文案映射

仅在用户未指定动作时，根据文字语气选择克制的静态姿态；用户指定动作时以用户要求为准。

| 情绪或语义 | 建议姿态 |
| --- | --- |
| 好的、收到、明白、谢谢 | 点头感、竖拇指或轻微微笑 |
| 开心、好耶、开饭、庆祝 | 举手、握拳庆祝或张开笑容 |
| 震惊、真的吗、啊？ | 睁大眼、微张嘴或双手停顿 |
| 不要、拒绝、生气、急了 | 摆手、交叉手势或皱眉 |
| 无语、疑惑、让我想想 | 歪头、托腮或侧目 |
| 晚安、困、放空 | 半闭眼、抱枕或轻微低头 |

## 生成提示词模板

每枚表情使用一份独立提示词，并明确列出输入图片角色。不要在不同表情之间省略身份不变量。

```text
Use case: style-transfer
Asset type: transparent static sticker master
Primary request: 根据人物参考截图，绘制用于微信群表情包的 Q 版半身贴纸无文字母图，表现“<情绪/姿态>”。
Input images: 图片 1..N 为同一人物的身份与姿态参考；如有风格母版，它是人物比例与画风主参考。
Subject: 保留 <从截图提炼的稳定身份特征>。
Style/medium: 干净的 Q 版数字插画，粗细一致的深色轮廓，简洁色块和轻阴影。
Composition/framing: 1024×1024 正方形，居中半身，给 <顶部/底部> 字幕留出安全区，四周留出白色贴纸描边空间。
Constraints: 真正透明背景；只出现用户指定的人物；不包含任何文字；不包含水印、Logo、场景、地面或投影；人物身份与服装特征稳定。
Avoid: 写实照片感、复杂背景、额外肢体、手指错误、裁切头发、棋盘格假透明、文字或乱码。
```

## 后续表情编辑模板

```text
Use case: identity-preserve
Asset type: transparent static sticker master
Primary request: 编辑已确认的 Q 版母图，仅把姿态和表情改成“<目标姿态/表情>”。
Input images: 图片 1 是要编辑的已确认 Q 版母图；其余图片是当前姿态或服装细节参考。
Changes: <逐项描述手势、表情、视线、身体与道具变化>。
Invariants: 人脸身份、发型、眼镜、服装、色板、线条、人物比例、相机视角、透明画布和字幕安全区不变。
Constraints: 真正透明背景；只出现原有人物；不包含文字、Logo、水印、场景、地面或投影。
Avoid: 重新设计人物、改变服装、增加肢体、手指错误、棋盘格假透明、文字或乱码。
```

## 240×240 导出建议

- 先生成至少 1024×1024 的透明母图，再由脚本一次性缩小，避免反复缩放造成锯齿。
- 默认人物白边约为 5 像素；文字描边随字号缩放。
- 短文案优先单行居中；长文案先尝试缩小字号，仍不清楚时再由用户提供或确认换行文本。
- 成套表情确认一种文字风格后，后续固定主字色、高亮色、双层描边、阴影和字幕上提量，避免不同图片之间出现样式漂移。
- 保持 RGBA PNG，不量化为索引色；半透明抗锯齿边缘应保留。
- 透明边缘出现灰黑杂边时，回到母图或合成步骤修复，不用不透明底色遮盖。
