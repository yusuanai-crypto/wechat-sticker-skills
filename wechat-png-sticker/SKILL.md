# WeChat-PNG-Sticker

## 默认创作档案

除非用户在本次请求中明确覆盖，否则采用以下规格：

- 用途：微信群个人粉丝交流。
- 风格：Q 版半身贴纸，保留人物最有辨识度的脸型、发型、眼镜、服装和配饰。
- 动作：选择一个清楚、适合文案语气的静态手势与表情；不制作动画帧或动态格式。
- 背景：真正透明；人物使用白色贴纸描边。
- 文字：逐字采用用户提供的精确文本，不让图像模型直接生成汉字。默认采用粗手写漫画标题字：主文字白色，最多一个核心词组使用黄橙色，外加粗黑内描边、较细白色外描边和轻微右下灰影；整体紧凑、有动势，并在底部轻叠人物下缘。
- 构图：正方形；先生成高分辨率透明 PNG 母图，再确定性合成为 240×240 RGBA PNG。
- 禁止无请求添加频道标志、水印、额外人物、额外文字或新口号。

用户当次明确要求优先于这些默认值，但不要把一次性变化写回本 Skill，除非用户要求更新默认偏好。

## 必需输入

开始制作前必须具备：

1. 至少一张清晰人物截图；多张截图可共同作为身份、服装和姿态参考。
2. 每个表情对应的精确文字，或用户明确要求无文字。

动作、情绪和文字位置可以省略：优先从用户指定或最清晰的截图选择姿态，并按文案语气做克制调整。多张连续截图只用于理解身份和选择最有表现力的静态时刻，不把它们制作成动作序列。若缺少截图或文字，也只询问一次；其余细节按默认档案推进。

如果截图来自本地文件，先用图像查看工具检查。把截图标记为“人物身份与姿态参考”，而不是要逐像素修改的编辑目标。不要根据外貌推断敏感属性。

## 制作流程

1. 阅读 [references/style-spec.md](references/style-spec.md)，据此选择姿态、构图和生成提示词。
2. 检查全部截图，分别提炼稳定的身份锚点、服装色块、标志性配饰，以及目标手势、表情、视线和道具状态。
3. 若 `assets/character-style-anchor.png` 存在，先检查并把它作为画风与人物比例的主参考，新截图作为身份、服装、表情或角度的辅助参考。若不存在，不要阻塞首次制作。
4. 为每个表情生成一张 1024×1024 或更高分辨率的透明 Q 版无文字母图。多枚表情属于同一套时，后续图片以已确认母图为风格和身份参考，锁定脸、发型、服装、色板、线条、人物比例和相机视角，只改变本枚表情需要的姿态与表情。
5. 检查母图的人物相似度、透明度、手部、轮廓、服装和安全区。一次只针对一个明确问题迭代，避免无关漂移。
6. 将选定母图复制到当前工作区的 `output/wechat-png-sticker/<batch-name>/masters/`，使用描述性文件名。不要把项目使用的唯一副本留在默认生成目录。
7. 检查母图，按 `style-spec.md` 组合粗手写字形、白色主字、黄橙关键词、黑色内描边、白色外描边和右下灰影。只在原文中存在明确核心词时，用 `--highlight-text` 指定一个连续且只出现一次的精确子串；不得为了高亮改写文案。若默认字形、层次或位置不适合画面，使用 `--font`、`--text-fill`、`--text-stroke`、`--text-outer-stroke`、`--highlight-fill`、`--text-shadow` 和 `--caption-lift` 显式覆盖。成套表情优先复用已确认的文字样式。
8. 使用 `scripts/build_png.py` 添加人物白边、精确文字并导出 240×240 PNG。若系统没有命令名为 `python` 的解释器，使用当前环境提供的 Python 可执行文件。脚本依赖 Pillow；先检测依赖，缺失时说明所需安装操作，不要静默安装。
9. 检查最终 PNG 的实际尺寸、alpha 透明度、人物辨识度、手部、文字准确性、粗手写漫画感、双层描边完整度、关键词高亮克制程度、文字与人物的轻叠关系、小尺寸可读性、透明边缘和文件体积。若文字拥挤，优先缩小字号或换行；不要压住眼睛和主要表情。
10. 交付最终 PNG 和母图路径，并报告实际尺寸、文件体积、文字位置、字体与配色，以及最终生成或编辑提示词。

## 静态 PNG 合成

每枚表情使用一次 `scripts/build_png.py`：

```powershell
python scripts/build_png.py `
  --input output/wechat-png-sticker/demo/masters/chigua.png `
  --output output/wechat-png-sticker/demo/chigua-240.png `
  --text "你在吃瓜吗?" `
  --highlight-text "吃瓜" `
  --size 240 `
  --text-position bottom
```

脚本会裁掉母图多余透明边缘，预留字幕安全区，添加白色人物贴纸描边，并使用支持中文的粗手写字体逐字绘制文案。默认文字为白色主字、黄橙关键词、粗黑内描边、白色外描边和右下灰影；必须检查成图，必要时用十六进制颜色或明确宽度参数覆盖。`auto` 仅作为用户要求随画面取色时的可选值。默认输出为 240×240 RGBA PNG；只有用户明确要求其他尺寸时才覆盖 `--size`。

## 首次校准与固定母版

用户一次要求整套表情时，首次优先制作两个代表性表情：一个常规、一个夸张。用户确认后再扩充整套；若用户只要求一枚，直接完成该枚，不强制追加样例。

如果用户明确要求“以后都沿用这个人物/画风”，可把确认后的无文字透明母图复制为 `assets/character-style-anchor.png`。写入已安装的 Skill 可能需要文件权限；执行前准确说明目标。未获此要求时，只在本次输出目录保留候选母版。

## 边界

- 默认仅按用户声明的个人粉丝交流用途处理。若用途改为销售、广告或官方宣传，提醒其自行确认人物肖像、截图与标志的使用授权。
- 不把静态截图扩展为仿真人讲话、换脸或误导性真人内容；输出应保持明显的 Q 版表情包属性。
- 不输出 GIF、动态 WebP、视频或动作关键帧序列；用户明确要求动态格式时改用相应动态表情工作流。
- 不覆盖既有输出文件；除非用户明确要求替换，否则使用新批次目录或版本化文件名。
